# Evidence snapshot: 9 August 2026

This directory is the compact audit record for the
[validation report](../../validation.md). It replaces the earlier prose-only
claims with outputs from actual Seurat and BioLang executions on the same HBC
ctrl/stim matrices.

## What is retained

- [`comparison.json`](./comparison.json): all cell, feature, neighborhood, and
  marker measurements reported by the book.
- [`seurat/cells.csv.gz`](./seurat/cells.csv.gz) and
  [`biolang/cells.csv`](./biolang/cells.csv): the exact joined cell identities,
  cluster labels, and UMAP coordinates used for ARI and mapped accuracy.
- Both 3,000-feature lists and both positive marker tables.
- Seurat's cluster trajectory and input manifest, plus byte-exact R session and
  run/marker logs in [`seurat/logs-and-session.zip`](./seurat/logs-and-session.zip).
- BioLang's summary, backend-bearing
  [`run log`](./biolang/run-log.zip), stopwatch result, and UMAP SVG.
- [`sha256.txt`](./sha256.txt): hashes for all source matrices and validation
  outputs, including the two large PC manifests that are intentionally not
  copied into the book.

The compact snapshot does not contain raw HBC matrices or the 34 MB of PC CSVs.
They are regenerated by the scripts below; their exact hashes bind the reported
PC-neighborhood comparison to the measured files.

## Reproduce the external oracle

From the repository root, with Seurat installed in a separate R library:

```powershell
$env:BIOLANG_VALIDATION_R_LIB = (Resolve-Path .validation-r-library)
& 'C:\Program Files\R\R-4.5.2\bin\Rscript.exe' `
  packages/singlecell/examples/validation/hbc_seurat_reference.R `
  ctrl_raw stim_raw validation-results/hbc-seurat

& 'C:\Program Files\R\R-4.5.2\bin\Rscript.exe' `
  packages/singlecell/examples/validation/hbc_seurat_markers.R `
  ctrl_raw stim_raw validation-results/hbc-seurat/cells.csv.gz `
  validation-results/hbc-seurat
```

Those scripts are validation-only. They are never imported, linked, invoked,
or required by BioLang, Cargo, package tests, notebook execution, or book
builds.

## Reproduce BioLang and compare

```powershell
cargo build --release -p bl-cli
target/release/bl.exe notebook `
  packages/singlecell/examples/hbc_course_validation.bln

.venv-scanpy/Scripts/python.exe `
  packages/singlecell/examples/validation/compare_hbc_results.py `
  validation-results/hbc-seurat `
  validation-results/hbc-biolang `
  validation-results/hbc-comparison.json
```

The comparison joins cells by `sample::barcode`, uses permutation-invariant
cluster metrics and an optimal one-to-one cluster assignment, compares PC
neighbors with seeded NNDescent, and compares two-dimensional UMAP neighbors
with an exact k-d tree.
