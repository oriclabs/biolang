Origin of Replication (oric package)

The oric package predicts candidate bacterial origins of replication (oriC) by combining two complementary signals: the GC skew reversal — the well-known asymmetry between leading and lagging strands that peaks near the origin — and the density of DnaA boxes, the conserved 9-mer motifs to which the DnaA initiator protein binds to unwind duplex DNA and nucleate replisome assembly.

Together these two signals produce a confidence score (0–5) for each candidate window. The package is designed for circular bacterial chromosomes but also works on linear replicons with reduced accuracy.

Installation

# Listed in biolang.toml dependencies — no separate install step needed
# biolang.toml:
# [dependencies]
# oric = "*"

Import

import "oric" as oric

Function Reference

predict_oric

The top-level prediction function. Scans the genome with a sliding window and returns a table of candidate oriC regions ranked by confidence score.

Signature: oric.predict_oric(seq, window_size?, step?) → Table

The result table has columns: start, end, confidence, skew_peak, dnaa_count, gc_skew_delta. Default window size is 500 bp; default step is 10 bp.

find_dnaa_boxes

Search a sequence for DnaA box occurrences using the consensus motif TTATCCACA (or species-specific variant) with configurable mismatch tolerance. Returns a list of { start, end, strand, mismatches, match } records.

Signature: oric.find_dnaa_boxes(seq, max_mismatches?) → List<Record>

gc_skew_profile

Compute the cumulative GC skew (G − C) / (G + C) across the full sequence in non-overlapping windows. Returns a table with columns position and skew.

Signature: oric.gc_skew_profile(seq, window_size?) → Table

find_skew_maximum

Return the position of the global GC skew maximum, which corresponds to the terminus of replication (terC) in circular chromosomes.

Signature: oric.find_skew_maximum(skew_table) → Int

find_skew_minimum

Return the position of the global GC skew minimum, which corresponds to the origin of replication (oriC) in circular chromosomes.

Signature: oric.find_skew_minimum(skew_table) → Int

scan_oric_table

Lower-level function that returns the full sliding-window scan table without filtering or ranking. Useful when you want to apply custom scoring criteria or visualize the raw signal across the entire chromosome.

Signature: oric.scan_oric_table(seq, window_size?, step?) → Table

plot_skew

Render a GC skew chart from the output of gc_skew_profile. Overlays predicted oriC candidates as vertical bands. Returns a chart value that can be saved or displayed inline.

Signature: oric.plot_skew(skew_table, candidates?) → Chart

Example 1: Quick oriC Prediction

Load an E. coli K-12 chromosome from a FASTA file, run the prediction, and print the top candidate: 

import "oric" as oric

# Load the genome
let genome_record = fasta("ecoli_k12.fa") |> first()
let genome = genome_record.seq
println("Genome length:", seq_len(genome))

# Predict oriC — default 500 bp window, 10 bp step
let candidates = oric.predict_oric(genome)

# Top result
let top = candidates |> head(1)
println("Predicted oriC:")
println("  Start:      ", top.start)
println("  End:        ", top.end)
println("  Confidence: ", top.confidence, "/ 5")
println("  DnaA boxes: ", top.dnaa_count)
println("  Skew delta: ", top.gc_skew_delta)

Example 2: Full E. coli K-12 Pipeline

A complete analysis pipeline that computes the GC skew profile, locates the skew minimum as an independent oriC estimate, finds DnaA boxes genome-wide, cross-checks the two signals, and plots the result: 

import "oric" as oric

let genome_record = fasta("ecoli_k12.fa") |> first()
let genome = genome_record.seq

# Step 1 — GC skew profile in 1 kb windows
let skew = oric.gc_skew_profile(genome, 1000)

# Step 2 — locate oriC and terC from skew extrema
let oric_pos = oric.find_skew_minimum(skew)
let terc_pos = oric.find_skew_maximum(skew)
println("Skew-based oriC estimate: position", oric_pos)
println("Skew-based terC estimate: position", terc_pos)

# Step 3 — DnaA box search in a 2 kb window around the skew minimum
let window_start = oric_pos - 1000
let window_end   = oric_pos + 1000
let region = subseq(genome, window_start, window_end)
let boxes  = oric.find_dnaa_boxes(region, 1)   # allow 1 mismatch
println("DnaA boxes found:", len(boxes))
for box in boxes {
  println("  pos", window_start + box.start, box.strand, "mismatches:", box.mismatches, box.match)
}

# Step 4 — full sliding-window scan for confidence scores
let candidates = oric.predict_oric(genome, 500, 10)
  |> filter(|r| r.confidence >= 3)
  |> sort_by(|candidate| -candidate.confidence)

println("High-confidence candidates:")
candidates |> print()

# Step 5 — plot the skew with oriC bands
oric.plot_skew(skew, candidates) |> save_svg("ecoli_skew.svg")

Example 3: Comparing Multiple Replicons

Screen every sequence in a multi-FASTA file (e.g., a plasmid collection) for potential oriC signatures: 

import "oric" as oric

# Stream all records from a multi-FASTA
let results = fasta("plasmids.fa")
  |> map(|rec| {
      let candidates = oric.predict_oric(rec.seq, 300, 5)
      let best = candidates |> head(1)
      {
        name:       rec.id,
        length:     seq_len(rec.seq),
        oric_start: best.start,
        confidence: best.confidence,
        dnaa_count: best.dnaa_count,
      }
    })
  |> to_table()

results |> print()

# Flag plasmids with a high-confidence oriC
results
  |> filter(|r| r.confidence >= 4)
  |> map(|r| println(r.name, "— strong oriC signal at", r.oric_start))

Confidence Score Interpretation

Each candidate window is assigned a confidence score from 0 to 5 based on how strongly both the GC skew and DnaA box signals agree:

Score Interpretation Typical use
5 Strong skew minimum and ≥3 DnaA boxes within the window High confidence; likely the true oriC
4 Clear skew minimum and 1–2 DnaA boxes, or strong DnaA cluster near skew minimum Good candidate for experimental follow-up
3 Moderate skew signal or DnaA boxes present but signals only partially overlap Worth investigating; validate with additional evidence
2 Weak skew or DnaA boxes at 1 mismatch only; signals disagree Low confidence; may be noise or secondary site
1 Minimal skew contribution, no exact DnaA boxes Very unlikely to be a functional oriC
0 No significant signal from either method Discard

DnaA Box Variants Across Species

The canonical DnaA box consensus TTATCCACA was defined in E. coli. Many other bacterial species use divergent consensus sequences. Notable examples:

Organism DnaA box consensus
E. coli / Enterobacteriaceae TTATCCACA
Bacillus subtilis TTATCCACA
Caulobacter crescentus TTAACCCGA
Helicobacter pylori TTTTCCACA

Pass max_mismatches: 1 or max_mismatches: 2 to find_dnaa_boxes when working with organisms whose consensus diverges from the E. coli reference. For fully custom motifs, use the core find_pattern builtin directly.

Relation to Core Builtins

The oric package is implemented entirely on top of BioLang core builtins; no native extensions are required. The key primitives it uses are:

Builtin Used for
find_pattern(seq, motif, max_mm) Locating DnaA box occurrences with mismatch tolerance on both strands
gc_skew(seq, window) Per-window (G−C)/(G+C) values used to build the cumulative skew profile
base_counts(seq) G and C counts for exact skew arithmetic within each candidate window
subseq(seq, start, end) Extracting candidate windows for focused DnaA box search and subsequence scoring

You can call these builtins directly if you need finer control over any step of the analysis. See Advanced Sequence Analysis for full documentation of find_pattern, gc_skew, and related functions.
