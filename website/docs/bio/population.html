Population Genetics & RNA-seq

BioLang provides built-in functions for two computationally intensive domains: population genetics (Hardy-Weinberg equilibrium, FST, linkage disequilibrium) and RNA-seq expression normalization (TPM, RPKM/FPKM). All functions operate on standard BioLang lists and records and compose naturally with the pipe operator.

Population Genetics

hardy_weinberg(aa_count, ab_count, bb_count)

Tests whether observed genotype counts at a biallelic locus conform to Hardy-Weinberg equilibrium (HWE) using a chi-square goodness-of-fit test with one degree of freedom. Allele frequencies are estimated directly from the observed counts:

  • p = (2 × AA + AB) / (2 × N)
  • q = 1 − p
  • Expected counts under HWE: exp_aa = N p², exp_ab = 2Npq, exp_bb = Nq²

The chi-square statistic is compared against the critical value at α = 0.05 (3.841) to determine in_equilibrium.

Return type

Field Type Description
pFloatFrequency of the reference allele (A)
qFloatFrequency of the alternate allele (B); equals 1 − p
nIntTotal number of individuals
obs_aa, obs_ab, obs_bbIntObserved genotype counts
exp_aa, exp_ab, exp_bbFloatExpected genotype counts under HWE
chi2FloatChi-square test statistic (1 df)
p_valueFloatTwo-tailed p-value
in_equilibriumBoolTrue when p_value ≥ 0.05

Basic example

# Test HWE for rs1801133 (MTHFR C677T) in a cohort of 1000 individuals
# Observed: CC=604, CT=319, TT=77
let hwe = hardy_weinberg(604, 319, 77)

println(hwe.p)               # => 0.7635  (C allele frequency)
println(hwe.q)               # => 0.2365  (T allele frequency)
println(hwe.n)               # => 1000
println(hwe.exp_aa)          # => 582.9
println(hwe.exp_ab)          # => 360.9
println(hwe.exp_bb)          # => 55.9 (note: slight excess of homozygotes)
println(hwe.chi2)            # => 3.18
println(hwe.p_value)         # => 0.074
println(hwe.in_equilibrium)  # => true

Batch HWE testing across a VCF

The typical use case is testing every variant site in a VCF for HWE deviation, which flags genotyping errors or genuine selection signals: 

# Genotype counts can be prepared from a VCF sample matrix
let variants = [
  {chrom: "chr22", pos: 17054720, ref: "G", alt: "A", aa: 44, ab: 12, bb: 7},
  {chrom: "chr22", pos: 18121455, ref: "C", alt: "T", aa: 50, ab: 21, bb: 4}
]

# Run HWE on every site
let hwe_results = variants
  |> map(|v| {
    let test = hardy_weinberg(v.aa, v.ab, v.bb)
    {
      chrom: v.chrom,
      pos: v.pos,
      ref: v.ref,
      alt: v.alt,
      p: test.p,
      q: test.q,
      chi2: test.chi2,
      p_value: test.p_value,
      in_equilibrium: test.in_equilibrium
    }
  })
  |> to_table()

# Identify sites departing from HWE (possible genotyping artefacts)
let hwe_failures = hwe_results
  |> filter(|r| !r.in_equilibrium and r.p_value < 0.001)
  |> sort_by(|r| r.p_value)

println("Total sites tested:", len(variants))
println("Sites failing HWE (p < 0.001):", len(hwe_failures))

hwe_failures |> head(10) |> println()
# chrom  pos        ref  alt  p       q       chi2   p_value
# chr22  17054720   G    A    0.312   0.688   18.41  0.00002
# chr22  18121455   C    T    0.891   0.109   12.77  0.00035
# ...

# Cache the HWE test to avoid recomputing per field
let hwe_cached = variants
  |> map(|v| merge(v, {hwe: hardy_weinberg(v.aa, v.ab, v.bb)}))
  |> filter(|r| !r.hwe.in_equilibrium)
  |> map(|r| {chrom: r.chrom, pos: r.pos, p_value: r.hwe.p_value})
  |> to_table()
  |> write_csv("output/hwe_failures.csv")

Heterozygosity excess detection

# GWAS QC: flag sites with excess heterozygosity (possible strand flips)
let excess_het = variants
  |> map(|v| {
    let test = hardy_weinberg(v.aa, v.ab, v.bb)
    merge(v, {
      hwe: test,
      het_obs: v.ab,
      het_exp: test.exp_ab
    })
  })
  |> filter(|r| r.hwe.obs_ab > r.hwe.exp_ab * 1.5 and !r.hwe.in_equilibrium)
  |> collect()

# => Sites with excess heterozygosity: 23

fst(pop_a_freqs, pop_b_freqs)

Computes Wright's FST from allele frequencies at N loci across two populations. For each locus the calculation follows the Weir & Cockerham approach expressed in terms of total and within-population heterozygosity:

  • Ht = 2 × p̄ × (1 − p̄) where p̄ = mean frequency across both populations
  • Hs = mean of [2pA(1−pA), 2pB(1−pB)]
  • FST = (Ht − Hs) / Ht

Loci where Ht = 0 (monomorphic in both populations) are excluded from the mean. The global fst_mean is the weighted average across all informative loci.

Return type

Field Type Description
fst_meanFloatMean FST across all informative loci
fst_per_locusList<Float>Per-locus FST values (same order as input)
n_lociIntNumber of loci included (after excluding monomorphic sites)

Basic example

# Compare allele frequencies between YRI (Yoruba) and CEU (European) populations
# for 8 well-known loci on chromosome 1
let yri_freqs = [0.72, 0.18, 0.55, 0.91, 0.43, 0.67, 0.29, 0.84]
let ceu_freqs = [0.41, 0.62, 0.53, 0.38, 0.45, 0.21, 0.77, 0.52]

let result = fst(yri_freqs, ceu_freqs)

println(result.fst_mean)         # => 0.187
println(result.n_loci)           # => 8
println(result.fst_per_locus)
# => [0.214, 0.352, 0.001, 0.538, 0.001, 0.423, 0.389, 0.097]

# High-FST loci are candidates for population-specific selection
let high_fst_indices = result.fst_per_locus
  |> enumerate()
  |> filter(|item| item[1] > 0.3)
  |> map(|item| item[0])
# => [1, 3, 5, 6]

Genome-wide FST scan between two population panels

# Load 1000 Genomes panel allele frequencies for AFR and EUR superpopulations

let panel = read_csv("data/1kg_afr_eur_freqs_chr1.csv")

ld_decay(variants, window_bp=1_000_000)

Estimates linkage disequilibrium (LD) decay across a chromosomal region by computing pairwise r² for all variant pairs within window_bp base pairs of each other, then binning the results into 10 equal-width distance bins. The r² between two SNPs is approximated from their allele frequencies using the composite haplotype estimator.

Input is a List<{pos: Int, freq: Float}> — one record per SNP containing its chromosomal position and the reference allele frequency. SNPs are assumed to be from a single chromosome and already filtered for MAF > 0.

Return type

Returns List<{distance: Float, r2_mean: Float, n_pairs: Int}> — one record per distance bin.

Field Type Description
distanceFloatMidpoint of the distance bin in base pairs
r2_meanFloatMean r² across all pairs in the bin
n_pairsIntNumber of SNP pairs contributing to this bin

Basic example

# LD decay in the MHC region (chr6:28–34 Mb) — a known region of extended LD
let mhc_snps = [
  {pos: 28_500_100, freq: 0.41},
  {pos: 28_502_890, freq: 0.67},
  {pos: 28_509_444, freq: 0.23},
  {pos: 28_518_710, freq: 0.55},
  {pos: 28_531_003, freq: 0.38},
  {pos: 28_548_200, freq: 0.71},
  {pos: 28_560_450, freq: 0.44},
  {pos: 28_577_800, freq: 0.19},
]

let decay = ld_decay(mhc_snps, 100_000)

decay |> println()
# distance  r2_mean  n_pairs
# 5000.0    0.742    4
# 15000.0   0.681    5
# 25000.0   0.603    6
# 35000.0   0.521    4
# ...

# The half-decay point (r2 = 0.5) indicates the effective LD block size
let half_decay = decay |> filter(|b| b.r2_mean >= 0.5) |> last()
if half_decay != nil {
  println("LD half-decay distance:", half_decay.distance, "bp")
} else {
  println("LD did not reach r2 >= 0.5 in these bins")
}

RNA-seq Normalization

Raw read counts are not directly comparable between genes (longer genes capture more reads) or between samples (libraries differ in sequencing depth). BioLang's normalization functions implement the two most widely used methods: TPM, which corrects for both gene length and sequencing depth simultaneously, and RPKM/FPKM, which corrects sequentially.

tpm(counts, lengths)

Computes Transcripts Per Million (TPM) normalization. TPM is the preferred method for within-sample comparisons because per-sample TPM values always sum to 10&sup6;, making them directly comparable across samples when gene length distributions are similar.

The formula is applied in two steps:

  1. Reads Per Kilobase: RPKi = counti / (lengthi / 1000)
  2. Scale to per-million: TPMi = RPKi / ∑RPK × 106

Both counts and lengths accept List<Int> or List<Float>. Genes with a count of 0 yield TPM = 0. A length of 0 raises a runtime error.

Return type

List<Float> — TPM values in the same order as the input lists.

Basic example

# Five genes with varying expression and transcript lengths
let gene_names = ["GAPDH",  "ACTB",  "TP53",  "BRCA1",  "MYC"]
let counts     = [  84200,    63100,    1820,     940,    7350]   # raw read counts
let lengths    = [   1364,     1798,    2629,    5592,    2354]   # transcript length (bp)

let tpm_vals = tpm(counts, lengths)
# => [30052.4, 17053.8, 336.7, 81.7, 1518.6]

# All TPM values sum to 1,000,000
tpm_vals |> sum() |> println()   # => 1000000.0 (within floating-point precision)

# Annotate with gene names
let expr = zip(gene_names, tpm_vals)
  |> map(|pair| {gene: pair[0], tpm: pair[1]})
  |> sort_by(|r| -r.tpm)

expr |> println()
# gene   tpm
# GAPDH  30052.4
# ACTB   17053.8
# MYC     1518.6
# TP53     336.7
# BRCA1     81.7

Normalizing a full count matrix from CSV

# Count matrix: rows = genes, columns = sample_id + count columns
# Gene length annotations from GTF/BED file
let count_matrix = read_csv("data/star_gene_counts.csv")
# gene_id         length  Sample_A  Sample_B  Sample_C  Sample_D
# ENSG00000111640  1364    84200    71300     92100     68400   (GAPDH)

# ENSG00000141510  2629     1820     2340      1580      2910   (TP53)

# ENSG00000136997  2354     7350     8820      6940      9210   (MYC)
# ... (25,000 genes total)

let tpm_table = gene_ids
  |> enumerate()
  |> map(|pair| {

    Sample_A: tpm_matrix[0].values[pair[0]],

    Sample_C: tpm_matrix[2].values[pair[0]],
    Sample_D: tpm_matrix[3].values[pair[0]],
  })

tpm_table |> write_csv("output/tpm_normalized.csv")

Filtering low-expression genes before downstream analysis

# Remove genes with TPM < 1 in all samples (unexpressed or very lowly expressed)
let gene_names = count_matrix |> col("gene_id") |> collect()
let lengths    = count_matrix |> col("length")   |> map(to_int) |> collect()

let tpm_a = tpm(count_matrix |> col("Sample_A") |> map(to_int) |> collect(), lengths)
let tpm_b = tpm(count_matrix |> col("Sample_B") |> map(to_int) |> collect(), lengths)
let tpm_c = tpm(count_matrix |> col("Sample_C") |> map(to_int) |> collect(), lengths)
let tpm_d = tpm(count_matrix |> col("Sample_D") |> map(to_int) |> collect(), lengths)

let expressed_genes = range(len(gene_names))
  |> filter(|i| max([tpm_a[i], tpm_b[i], tpm_c[i], tpm_d[i]]) >= 1.0)
  |> map(|i| gene_names[i])
  |> collect()

println("Expressed genes (TPM >= 1 in at least one sample):", len(expressed_genes))
# => Expressed genes (TPM >= 1 in at least one sample): 16843

rpkm(counts, lengths, total_mapped?)

Computes Reads Per Kilobase per Million mapped reads (RPKM), also called FPKM (Fragments Per Kilobase per Million) when applied to paired-end data where fragments rather than individual reads are counted.

The formula is:

RPKMi = counti / (lengthi / 1000) / (total_mapped / 106)

When total_mapped is omitted it defaults to sum(counts). Note that unlike TPM, RPKM values do not sum to a fixed constant, which means sample-to-sample comparisons require additional care. RPKM is nonetheless widely used in legacy datasets and for compatibility with older tools.

Parameters

Parameter Type Description
countsList<Int|Float>Raw read counts per gene
lengthsList<Int|Float>Effective gene lengths in base pairs
total_mappedInt|Float (optional)Total mapped reads; defaults to sum(counts)

Return type

List<Float> — RPKM/FPKM values in the same order as the input lists.

Basic example

let gene_names = ["GAPDH",  "ACTB",  "TP53",  "BRCA1",  "MYC"]
let counts     = [  84200,    63100,    1820,     940,    7350]
let lengths    = [   1364,     1798,    2629,    5592,    2354]

# Default: total_mapped = sum(counts)
let rpkm_vals = rpkm(counts, lengths)
# => [27968.2, 15866.4, 313.2,  76.0,  1413.0]

# With an externally supplied total (e.g. from STAR alignment log)
# Useful when counts matrix is pre-filtered and total_mapped differs
let total = 48_200_000   # total uniquely mapped reads from STAR log
let rpkm_ext = rpkm(counts, lengths, total)
# => [1280.7, 726.5, 14.3, 3.5, 64.7]

# Annotate and compare RPKM vs TPM
let tpm_vals = tpm(counts, lengths)
let comparison = range(len(gene_names))
  |> map(|i| {gene: gene_names[i], rpkm: rpkm_ext[i], tpm: tpm_vals[i]})
  |> sort_by(|r| -r.tpm)

comparison |> println()
# gene   rpkm    tpm
# GAPDH  1280.7  30052.4
# ACTB    726.5  17053.8
# MYC      64.7   1518.6
# TP53     14.3    336.7
# BRCA1     3.5     81.7

Comparing expression between samples with supplied totals

# Using FPKM (paired-end counts are fragment counts)

Combined Workflow: Population-Stratified RNA-seq

A realistic research scenario: you have RNA-seq data from individuals in two population cohorts and want to (a) check variant sites for HWE in each cohort, (b) compare allele frequencies via FST, and (c) normalize expression so you can correlate expression with genotype. The following pipeline ties all five functions together. 

# ── Step 1: Load data ──────────────────────────────────────────────────────
# Genotype counts per SNP, split by cohort
let snp_table = read_csv("data/cohort_genotypes.csv")
# rsid       chrom  pos        afr_aa  afr_ab  afr_bb  eur_aa  eur_ab  eur_bb
# rs4988235  chr2   136608646  412     171      17       48     189     263
# rs1426654  chr15  48388191   591     7         2       29     138     333
# ...

# RNA-seq count matrix (same individuals)
let counts_csv = read_csv("data/rnaseq_counts.csv")    # gene_id, length, AFR_*, EUR_*
let gene_ids   = counts_csv |> col("gene_id") |> collect()
let lengths    = counts_csv |> col("length")  |> map(to_int) |> collect()

# ── Step 2: HWE testing in each cohort ─────────────────────────────────────
let hwe_report = snp_table
  |> map(|row| {
    {
      rsid: row.rsid,
      chrom: row.chrom,
      pos: row.pos,
      afr_hwe: hardy_weinberg(row.afr_aa, row.afr_ab, row.afr_bb),
      eur_hwe: hardy_weinberg(row.eur_aa, row.eur_ab, row.eur_bb)
    }
  })
  |> map(|r| {
    {
      rsid: r.rsid,
      chrom: r.chrom,
      pos: r.pos,
      afr_p: r.afr_hwe.p,
      eur_p: r.eur_hwe.p,
      afr_hwe_ok: r.afr_hwe.in_equilibrium,
      eur_hwe_ok: r.eur_hwe.in_equilibrium
    }
  })
  |> collect()

let hwe_pass = hwe_report |> filter(|r| r.afr_hwe_ok and r.eur_hwe_ok) |> collect()
println("SNPs passing HWE in both cohorts:", len(hwe_pass))  # => 1,847 of 2,000

# ── Step 3: Population differentiation (FST) ───────────────────────────────
let afr_freqs = hwe_pass |> map(|r| r.afr_p) |> collect()
let eur_freqs = hwe_pass |> map(|r| r.eur_p) |> collect()

let pop_diff = fst(afr_freqs, eur_freqs)
println("Mean FST (AFR vs EUR, HWE-filtered):", pop_diff.fst_mean)  # => 0.098

# Tag HWE-passing SNPs with their per-locus FST
let snps_with_fst = hwe_pass
  |> zip(pop_diff.fst_per_locus)
  |> map(|pair| merge(pair[0], {fst_value: pair[1]}))
  |> sort_by(|r| -r.fst_value)
  |> collect()

let high_fst_snps = snps_with_fst |> filter(|r| r.fst_value > 0.3) |> collect()
println("High-FST SNPs (> 0.3):", len(high_fst_snps))  # => 34

# ── Step 4: TPM normalization for each cohort ──────────────────────────────
# Identify AFR and EUR sample columns
let afr_samples = counts_csv |> columns() |> filter(|c| c |> starts_with("AFR_"))
let eur_samples = counts_csv |> columns() |> filter(|c| c |> starts_with("EUR_"))

let tpm_afr = afr_samples
  |> map(|s| tpm(
      counts_csv |> col(s) |> map(to_int) |> collect(),
      lengths
    ))
  |> collect()   # List of per-sample TPM vectors

let tpm_eur = eur_samples
  |> map(|s| tpm(
      counts_csv |> col(s) |> map(to_int) |> collect(),
      lengths
    ))
  |> collect()

# Mean TPM per cohort for each gene
let mean_tpm_afr = range(len(gene_ids))
  |> map(|i| tpm_afr |> map(|v| v[i]) |> mean())
  |> collect()

let mean_tpm_eur = range(len(gene_ids))
  |> map(|i| tpm_eur |> map(|v| v[i]) |> mean())
  |> collect()

# ── Step 5: Report ──────────────────────────────────────────────────────────
let final_table = range(len(gene_ids))
  |> map(|i| {
    {
      gene_id: gene_ids[i],
      tpm_afr: mean_tpm_afr[i],
      tpm_eur: mean_tpm_eur[i],
      log2_fc_afr_eur: log2((mean_tpm_afr[i] + 0.1) / (mean_tpm_eur[i] + 0.1))
    }
  })
  |> sort_by(|r| -r.log2_fc_afr_eur)
  |> to_table()

final_table |> write_csv("output/population_expression_report.csv")
println("Pipeline complete — output written to output/population_expression_report.csv")
